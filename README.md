An entry for [make.fun's "Monday Morning Punchlines" bounty](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) — one joke about Monday mornings, at most 200 characters. Top three share $5 ($2 / $2 / $1).

## The joke

> Monday morning, my reflection called in sick. I had to go in for both of us.

76 characters. The mirror image refuses Monday and the speaker has to cover its shift — a turn that lands, not a complaint. The mirror/reflection lane is unused in the live field (0 of 233 titles), unlike the crowded alarm/snooze lane (44), bed-custody lane (19) and HR/boss lane (9).

## How it works

`main.py` uses only the Python 3 standard library and makes no network calls. It checks the joke against the gate (1–200 characters, not only whitespace, valid UTF-8), writes it to `/output/entry.txt`, and prints the character count. It exits 0 on success and raises on any gate failure.

## How to run

```sh
python3 main.py
```
